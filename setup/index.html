SETUP GUIDE

はじめての
アプリ設定ガイド

配信をはじめる前の準備。
IRIAM のアカウント作成から、X との連携まで
画像付きで丁寧に案内します。

① IRIAM ② X アカウント ③ IRIAM × X 連携
STEP 01

IRIAM のアカウントを作る

まずは配信用のアプリ「IRIAM」をダウンロードし、アカウント作成 → メールアドレス登録までを行います。

STEP 02

X（旧Twitter）アカウントを作る

配信告知やファンとの交流に使う X アカウントを、ライバー用に新規で作成します。

STEP 03

IRIAM と X を連携する

IRIAM のマイページから X アカウントを連携し、プロフィールに IRIAM のリンクを設置します。

NEXT STEP

設定が終わったら、
あとは配信をはじめるだけ。

迷ったとき、うまく進まないとき、いつでも公式LINEで相談できます。
SELFiA スタッフが個別にサポートします。

公式LINEで相談する まず妖精タイプ診断を受ける

相談だけでもOK。
